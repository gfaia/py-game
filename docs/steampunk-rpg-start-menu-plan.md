# 蒸汽朋克开场菜单

## Summary

在游戏启动时先显示全屏开场画面。画面显示标题 `Brass Station`，以及 `Start Game` 和 `Quit` 两个菜单项。玩家可以用鼠标或键盘操作菜单。

## Key Changes

- 在 `steampunk_rpg/main.py` 的 `Game` 中加入菜单状态和当前菜单项。
- 新增菜单绘制方法。画面使用现有黄铜、深色和浅色调，显示标题、操作提示和两个纵向菜单项。
- 启动时进入菜单状态，不创建可操作的游戏流程。
- 支持上、下方向键和 `W`、`S` 切换选项。当前选项使用高亮背景和边框。
- 支持鼠标移动高亮菜单项，左键点击执行对应操作。
- 支持 `Enter` 确认当前选项。
- 选择 `Start Game` 时，重置 `World` 并进入现有游戏画面。
- 选择 `Quit` 时，关闭主循环和 Pygame 窗口。
- 在菜单状态按 `Esc` 时，执行 `Quit`。
- 游戏中的移动、交互、攻击、重开和退出规则保持不变。

## Test Plan

- 启动游戏时显示开场菜单，不显示可操作的游戏 HUD。
- 键盘和鼠标均可在两个菜单项之间切换高亮。
- `Enter` 和鼠标点击 `Start Game` 后，玩家从初始位置开始新游戏。
- `Enter` 和鼠标点击 `Quit` 后，程序正常退出。
- 菜单状态按 `Esc` 后，程序正常退出。
- 启动后在 Python 3.12 虚拟环境中完成一次无窗口绘制检查。

## Assumptions

- 菜单文字保持英文，与当前游戏 HUD 一致。
- 菜单只在游戏启动时出现，不加入游戏内暂停菜单。
- `Start Game` 始终开始新的游戏，不恢复旧状态。
