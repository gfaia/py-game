# 横版丧尸生存

这是一款像素风、故事情节导向的横版丧尸游戏。

玩家将在丧尸危机后的城市与荒野中前进，寻找幸存者、收集资源，并逐步了解灾难发生的原因。游戏通过场景、角色对话和关键事件推动剧情，让每次战斗与探索都服务于故事。

游戏整体采用压抑、孤独但保留希望的末日氛围。像素画面表现破败环境和紧张战斗，横版视角让玩家专注于前进路线、资源取舍与生存选择。

## 游戏配置

游戏每次启动时读取 `game_config.toml`。你可以在该文件修改白天和夜晚时长、初始武器、初始弹药、角色属性、丧尸属性、子弹属性和安全屋大门生命值。

初始武器可以设为 `gun`、`pistol` 或 `shotgun`。修改 TOML 文件后，重新启动游戏即可加载新配置。
